## ✦ Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/RajanGaur01/Rj-portfolio.git

# Navigate into the project directory
cd Rj-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Environment Setup (Local & Vercel)

Create a `.env.local` file in your root folder (or add these variables in your **Vercel Project Settings > Environment Variables**):

```env
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project_id.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_project_id.firebasestorage.app
VITE_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
VITE_FIREBASE_APP_ID=your_app_id
VITE_FIREBASE_MEASUREMENT_ID=your_measurement_id
```

> **Note**: A template file [`.env.example`](.env.example) is provided in the repository.

### Production Build

```bash
npm run build
```
